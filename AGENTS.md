When applicable dotfiles should be compatible on most Linux distributions and macOS (for the latter, under a typical Homebrew-managed system). Avoid using configuration options and standards that require newer versions of an older program when an older option exists that works just as well. Cross compatibility does not apply for programs that are exclusive to specific operating systems. Bash scripts may not use GNU-specific flags, and should avoid calling commands or using Bash features that might not be on a typical install of all systems.
